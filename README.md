# Bloodlot Ascension

A dark fantasy roguelike where every blade is a roll and every roll is a prayer.
Weapons and accessories drop at rarities from Common to Ascended (1 in 100,000) and Transcendent (1 in 1,000,000).

**Play:** open the GitHub Pages link of this repository, or download `index.html` and open it in a browser.

The whole game is a single HTML file. Progress is saved in your browser.

## Controls

| Key | Action |
|---|---|
| WASD | move |
| Mouse / Space | attack (hold) |
| Shift | dash (needs a dash skill) |
| Q | god ability |
| R | roll a Fate Die |
| F | shrines, altars, chests, stairs |
| 1–6 · I · P | potions · inventory · pause |

Patch notes are in the game: **What's new** on the title screen.

## Download

Grab the latest **Bloodlot-Ascension-vX.zip** from the [Releases page](../../releases/latest), unzip it and open `Bloodlot-Ascension.html` in your browser.
